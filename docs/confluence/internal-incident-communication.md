Example Internal Communication Subject: GPTE Infra incident | functionality impact When an incident is in-progress: Communicate via slack in #rhdp-troubleshooting (tag @ here ) and make sure to give a blurb about the IMPACT of the incident. Start a video-session for Swarm using /meet in the #rhdp-troubleshooting slack channel Contact the awake Infra/Infra-dev and management representative - see the if you can't find them online,. Post something like this to #rhdp-troubleshooting : Escalating issues directly IF SOMEONE IS NOT SEEING THE ISSUE: keep contacting them Make sure that you have a clear picture of the issue and explain it as clearly. Make sure you keep the issue on #rhdp-troubleshooting instead of directly contacting. Escalate up the management chain - starting with the on-call manager and/or your manager until you get an answer. Unfortunately, this is the reality of our team until ticketing is available and properly in-use by all sub-teams: You are responsible for ensuring the issue is seen by the appropriate people.
