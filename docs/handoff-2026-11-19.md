## Guardrails

- Read-only on clusters; no Secrets, no values. Keys live in
  `~/Documents/jkershaw-mcp-key.txt` — reference the path, never paste the key.
- The Babylon control plane is `kubeconfig-ocp-us-east-1` inside the pod;
  infra01 does **not** host Anarchy CRDs.
- API deployments are digest-pinned: always `oc set image` after a build.
- Do not deploy within 15 minutes of a demo; brief 502s during rollout make the
  demo fall back to REHEARSAL.
- `event_log.failure_class` can contain comma-joined lists — split before
  grouping.
